tr181ctl Playground

A small C99 tool that exposes a Linux device as a TR-181 data model. It reads /proc and /sys/class/net, answers ubus-cli-style queries and prints USP (TR-369) GetResp JSON. This page runs a browser copy of the same logic with sample data from a router.

How it works

  • Every parameter is produced by a getter and handed to a visitor callback, so get, json and schema share one tree walk.
  • A path ending in . is a partial path and returns the whole object, as in USP.
  • set checks access and type (unsignedInt, boolean, string) before writing.
  • Linux operstate is mapped to the TR-181 Status enum.

Build and run

make && make test
./tr181ctl get Device.Ethernet.Interface.1.
./tr181ctl json Device.DeviceInfo.
./tr181ctl shell

# OpenWrt: copy packaging/openwrt into package/tr181-agent, then
make package/tr181-agent/compile
# Yocto: add packaging/yocto/tr181-agent_1.0.0.bb to your layer, then
bitbake tr181-agent
The three sample devices use dummy data, and changes you make reset when you reload. On a real device every value comes from the kernel.
